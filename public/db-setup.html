KI-Kernel GPT 2.0 · kontrollierter DB-Import

Datenbankmigration kontrolliert ausführen

Diese Seite steuert die DB-Vorbereitung: Status prüfen, Tabellen anlegen, Backup serverseitig prüfen und kontrolliert importieren. Die App bleibt danach weiterhin im LocalStorage-Modus, bis du bewusst auf Hybridbetrieb umstellst.

Zur App Backup Projektakte

Sicherheitslogik

Nicht auf STORAGE_MODE=hybrid oder db umstellen, bevor Schema-Anlage, Dry Run und Import erfolgreich waren. Der echte Import benötigt die Bestätigungsphrase IMPORT IN DATENBANK.

1. Systemstatus

Liest /api/health.

2. DB-Status

Liest /api/db/status und prüft, ob PostgreSQL erreichbar ist und Tabellen vorhanden sind.

3. Schema anlegen

Legt die Basistabellen in PostgreSQL an. Dieser Schritt ist idempotent: vorhandene Tabellen werden nicht gelöscht.

4. Backup laden und lokal analysieren

Lade ein Vollbackup aus Backup 1.6 hoch. Die lokale Analyse zeigt grob, ob Projekte, Szenarien und Verknüpfungen plausibel sind.

5. Kontrollierten Import ausführen

Dieser Schritt schreibt Projekte, Szenarien, Szenario-Versionen, Projekt-Szenario-Verknüpfungen, Phasen-Sets, Beratungsfälle und ein Audit-Log in PostgreSQL.
