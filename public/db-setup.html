Diese Seite prüft Umgebung, Backup-Dateien und Migrationsreife. Sie schreibt noch nichts in PostgreSQL. Der produktive Import folgt erst nach bewusstem Setup.

Zur App Backup Projektakte

Sicherheitslogik

Solange STORAGE_MODE=local gesetzt ist, bleibt der Browser-Speicher Hauptspeicher. Die Datenbank darf vorbereitet sein, wird aber nicht aktiv genutzt. Genau dieser Zustand ist vor einer Migration richtig.

1. Systemstatus

Liest /api/health und bewertet den Migrationsstand.

2. Nächste Coolify-Schritte

  1. PostgreSQL-Resource ist angelegt.
  2. DATABASE_URL ist bei der App gesetzt.
  3. STORAGE_MODE=local bleibt gesetzt.
  4. App ist redeployed.
  5. Diese Seite zeigt databaseConfigured: true.

3. Backup-Datei prüfen

Lade ein Vollbackup aus Backup 1.6 hoch. Die Datei wird nur lokal im Browser geprüft.

4. DB-Migrationsbefehle

Erst ausführen, wenn Prisma Client im Container korrekt generiert werden kann.

npm run db:generate
npm run db:migrate:deploy

Falls Coolify ein Terminal für die App anbietet, dort ausführen. Alternativ als einmaliger Job oder später über einen kontrollierten Setup-Endpunkt.
